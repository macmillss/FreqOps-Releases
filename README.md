# FreqOps Releases

Official downloads for FreqOps software. This repository holds release builds only.

Get the latest version from **[freqops.dev/software](https://freqops.dev/software/)**.

## Verify your download

Every release lists the file's SHA-256. To check a download in PowerShell:

```powershell
(Get-FileHash .\Digital-Transmissions-Log.exe).Hash
```

The result should match the SHA-256 shown in the release notes and on freqops.dev.
